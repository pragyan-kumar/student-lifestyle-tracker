## 📱 About the App

A unified mobile platform that helps students log daily lifestyle habits, track their carbon footprint, and receive AI-driven personalised recommendations — all wrapped in a gamification engine that rewards eco-friendly behaviour with in-app perks.

### Core Modules

| Module | Description |
|--------|-------------|
| 🛌 **Lifestyle Habit Tracker** | Log sleep, diet, exercise & screen time with streak detection |
| 🌿 **Carbon Emission Calculator** | Daily CO₂ footprint from commute, food & device usage via Carbon Interface API |
| 🤖 **AI Insights Engine** | scikit-learn model suggests healthier & greener alternatives |
| 🎮 **Gamification Engine** | Points wallet, badges, streak-freeze passes, theme unlocks |

## 🏗️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Flutter (Dart) |
| Backend | Node.js + Express.js |
| Database | MongoDB Atlas + Firebase Realtime DB |
| ML Service | Python 3.x, scikit-learn, pandas, FastAPI |
| Auth | Firebase Auth + JWT + OAuth2 |

| Hosting | Vercel (backend) + Firebase App Distribution |
